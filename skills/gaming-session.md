# Prepare the PC for a gaming session
1. {"tool": "game_mode", "state": "on"}
2. Ask the preferred volume, or set it to 50: {"tool": "set_volume", "level": 50}
3. Close only the windows the user names: {"tool": "close_window", "window": "..."}
4. {"tool": "system_info"} then report RAM, battery and disk space.
5. Mention that the Steam library is on D:\SteamLibrary when games come up.
